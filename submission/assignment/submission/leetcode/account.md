# LeetCode

## Problem
- **Problem:** Reverse String
- **Problem Number:** 344
- **Language:** C#
- **Approach:** Two Pointers

## Submission
- **LeetCode Profile:** https://leetcode.com/u/salmaelghareb/
- **Accepted Submission:** https://leetcode.com/submissions/detail/2136049674/
## Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)

## Solution Idea
I used two pointers: one starts from the beginning of the array and the other starts from the end. I swap the characters, then move both pointers toward the center until they meet.
